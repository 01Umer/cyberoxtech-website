FAQs

ISO 27018 — Common Questions

Is ISO 27018 only for cloud providers?+
It is primarily written for public cloud service providers processing PII, but cloud customers also benefit from using it to assess providers and define privacy requirements in contracts and due diligence.
How is ISO 27018 different from ISO 27701?+
ISO 27701 is a privacy management extension to ISO 27001. ISO 27018 is more specific to protecting PII in public cloud services. They complement each other.
Can Cyberox combine ISO 27018 with SOC 2 readiness?+
Yes. ISO 27018 controls can strengthen SOC 2 privacy and confidentiality evidence, especially for SaaS and cloud service providers.
